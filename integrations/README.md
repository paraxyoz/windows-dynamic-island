# Подключение дополнительных источников

## Dota 2 и FPS

В «Сводке → Компьютер» нажмите «Настроить Dota 2». Сохраните
gamestate_integration_dynamic_island.cfg в Steam\steamapps\common\dota 2 beta\game\dota\cfg\gamestate_integration
и добавьте -gamestateintegration в параметры запуска Dota 2. После перезапуска игры
остров покажет матч, героя, игровой таймер, K/D/A и счёт, если игра передала его.
Обмен идёт по адресу 127.0.0.1:40971 и защищён отдельным локальным токеном.
Токен автоматически создаётся в острове и не нужен для других программ.

В MSIX с PresentMon FPS измеряется для распознанного процесса игры.
Для сборки из исходников передайте официальный PresentMon 2.6.0 x64 и его LICENSE.txt
в installer/build-msix.ps1. Если Windows не даёт снять ETW-метрики,
остров показывает отсутствие данных FPS.

## Chrome и Edge

1. Распакуйте набор интеграций в постоянную папку.
2. В chrome://extensions или edge://extensions загрузите распакованное расширение из папки browser.
3. Скопируйте ID расширения из списка и выполните в PowerShell:

    .\register-browser.ps1 -ExtensionId ВАШ_ID -IslandExe 'C:\путь\WindowsDynamicIsland.exe' -Browser Chrome

Для Edge укажите -Browser Edge. Можно указать WindowsDynamicIsland.exe из набора интеграций.
Скрипт регистрирует Native Messaging только для текущего пользователя и указанного ID.
В остров передаются только имя файла и прогресс. URL и полный путь не передаются.

## Установка и распаковка

Остров слушает события установки и обновления MSIX для текущего пользователя.
Отдельный скрипт Python 3.9+ запускает операции через WinGet или установленный 7-Zip:

    python task_runner.py install ИДЕНТИФИКАТОР_ПАКЕТА --source msstore
    python task_runner.py extract 'D:\archive.7z' 'D:\unpacked'

Скрипт 7-Zip пропускает существующие файлы. Когда инструмент не сообщает общий объём или процент,
в острове отображается состояние «Выполняется». Ошибки и отмены не отмечаются успешными.

## Discord

Для локального RPC необходимо одобренное Discord приложение и пользовательский OAuth-токен.
Задайте ISLAND_DISCORD_CLIENT_ID и ISLAND_DISCORD_RPC_TOKEN в окружении процесса,
затем запустите python discord_bridge.py. Для микрофона и голосового канала нужен rpc.voice.read,
для сообщений и доступных событий вызова — rpc.notifications.read. Токен хранится только
в окружении процесса и отправляется локальному клиенту Discord для аутентификации.
Скрипт не читает токен самого Discord Desktop.

## Telegram

В отдельном окружении Python 3.9+ установите Telethon 1.x и задайте собственные
ISLAND_TELEGRAM_API_ID и ISLAND_TELEGRAM_API_HASH. Запустите python telegram_bridge.py и
войдите в Telegram в своей консоли. Мост пересылает в остров только новые входящие
личные сообщения. Для открытия конкретного чата нужен публичный username отправителя.
Папка TelegramBridge в локальном профиле Windows содержит авторизованную сессию,
поэтому не передавайте её другим. Остановить мост можно Ctrl+C.

Мосты работают независимо от системной службы уведомлений Windows.
Без разрешений Discord или без авторизованной сессии Telegram они не получают данные.
Для личного WhatsApp используется доступный системный источник уведомлений Windows.
